# 백로그

매일 자동화는 위에서부터 미완료 1건만 처리한다. 게임, 가벼운 콘텐츠, 개발 유틸 모두 가능하다. 비어 있으면 규칙을 따라 새 아이디어를 고른 뒤 여기에 적고 바로 만든다.

## 대기

- [ ] 음식 월드컵 — 두 음식 중 고르기를 반복해 우승을 가림
- [ ] 반응속도 테스트 — 화면이 바뀌면 클릭, 밀리초 기록
- [ ] 밸런스 게임 — A/B 중 하나를 고르는 짧은 질문
- [ ] 짧은 퀴즈 — 몇 문항 고르고 결과 한 장
- [ ] 가벼운 계산기 — 날짜 디데이, 팁 나누기처럼 바로 쓰는 도구
- [ ] 텍스트 비교 — 왼쪽/오른쪽에 붙여 넣고 다른 줄 표시
- [ ] 글자 수 세기 — 공백 포함/제외, 줄 수, 바이트
- [ ] SQL 쿼리 도우미 — SELECT/INSERT 뼈대나 WHERE 조건을 만들어 줌
- [ ] JSON 정리 — 붙여 넣은 JSON을 보기 좋게 정렬·오류 표시
