# 루프엔지니어

매일 웹에서 바로 해볼 수 있는 짧은 콘텐츠를 하나 추가하기 위한 규칙과 할 일 목록. 같은 기능은 다시 만들지 않는다. **기능을 만들면 메인 `index.html` 카드 링크는 반드시 넣는다.** 실험 모음에도 같은 카드를 넣고, 상단 메뉴는 `홈 / 사주 / 게임 / 실험 / 방명록`만 유지한다. 목표는 [neal.fun](https://neal.fun/)의 한국판이다. 결만 오마주하고 베끼지 않는다. 화면은 Pretendard·오프화이트·떠오르는 카드다. 자동화는 새 실험 폴더와 홈 카드만 만지고, `site.css`·기존 게임은 건드리지 않으며 **PR 생성 후 main 머지까지** 반영한다.
