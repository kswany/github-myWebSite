# 백로그

매일 자동화는 위에서부터 **아직 저장소·열린 PR에 없는** 미완료 1건만 처리한다. 같은 주제를 다시 만들지 않는다.

**턴 완료 = PR 생성 + main 머지 + 메인 `index.html` `.grid`에 카드.** PR만 열고 main에 안 올리면 미완성이다. `css/site.css`와 이미 있는 게임·실험 폴더는 수정하지 않는다. main에 직접 푸시하지 않는다 — PR을 머지한다.
