# 일일 기능 규칙

매일 한 번, 웹사이트에서 바로 해볼 수 있는 짧은 콘텐츠를 **딱 1개** 만들어 홈에 붙인다. 게임일 필요는 없다.

## 이미 있는 것 (다시 만들지 말 것)

- `saju/` — 사주팔자 계산
- `games/` — 그림 짝맞추기
- `experiments/food-worldcup/` — 음식 월드컵

## 한 턴에 할 일

1. 백로그에서 미완료 1건을 고른다. 비어 있으면 최근 한국 웹 트렌드 **또는 개발자가 구글에서 자주 찾는 유틸**로 아이디어 1개를 정한다. 게임, 테스트, 월드컵, 퀴즈, 계산기, 텍스트 비교, 글자 수, SQL/JSON 도구 모두 가능하다.
2. `experiments/<영문-slug>/index.html` 에 완성된 페이지를 만든다. 필요하면 같은 폴더에 CSS/JS를 둔다.
3. 루트 `index.html`의 `.grid`에 카드를 하나 추가한다. 기존 사주/게임 카드 형식과 같게 한다 (`kicker`, `h2`, `p`, `열기/플레이 →`).
4. 백로그를 갱신한다 (완료 표시 + 다음 후보 1~2개).
5. 동작을 확인한 뒤 **PR을 연다.** main에 직접 푸시하지 않는다.

## 반드시 지킬 것

- HTML/CSS/JS만. 서버, 로그인, 결제, 외부 API 키 없음.
- 방문자의 브라우저에서만 동작. 입력값은 서버로 보내지 않음. 기록은 localStorage만.
- 기존 사주/그림 짝맞추기를 깨지 않음.
- 안내 문구는 한국어. 개발 유틸은 입력란에 코드·영문이 들어가도 된다.
- 한 기능 용량은 작게 (큰 영상·이미지 넣지 않음).
- 기존 `css/site.css` 톤(먹색, 주홍, Gowun Batang)을 맞춘다.
- 저작권 있는 브랜드/캐릭터/가수는 쓰지 않음. 음식 월드컵은 일반 음식명만.
- 하루 1개. 미완성으로 끝내지 않음.

## 아이디어 예

재미: 음식·메뉴 월드컵, 반응속도 테스트, 밸런스 선택, 짧은 퀴즈, 오늘의 운세(사주와 다른 가벼운 버전).

개발 유틸: 두 텍스트 비교(diff), 글자 수/줄 수, SQL 쿼리 만들기, JSON 정리·검증, Base64 인코딩, URL 인코딩, 정규식 시험, 유닉스 시간 변환, UUID 만들기. 붙여 넣고 바로 결과가 나오면 된다. 외부 API 없이 브라우저에서만 계산한다.
